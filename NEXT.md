# Следующий шаг HELIOS

Сейчас следующий шаг — **проверить и принять R01**, уже предложенный в [PR #28](https://github.com/glebvin/helios/pull/28). Параллельно предложены R02 в PR #29 и R03 в PR #30. Они ещё не приняты и не объединены: повторно писать эти реализации не нужно.

Вместо самостоятельного аудита экранов передайте Cursor одну просьбу:

> Возьми только следующее действие HELIOS из NEXT.md в актуальной main. Если реализация уже предложена в PR, сначала проверь её по карточке; не создавай дубликат. Сначала прочитай README.md, AGENTS.md, CONTRIBUTING.md и карточку шага. Проверь папку, ветку и несохранённые изменения; чужую работу не сбрасывай. Используй отдельную ветку от main. Сохрани принятый интерфейс. Сам подготовь отдельные QA-данные, проверь функциональность и внешний вид, покажи работающий preview и PR с результатами проверок. Весь roadmap сразу не выполняй. Следующий шаг, merge и выкладку автоматически не начинай.

Владельцу остаётся посмотреть готовый preview и сказать, понятен ли результат и устраивает ли вид. Исследование API, подготовка фикстур и техническое тестирование выполняются агентом.

После фактической приёмки агент обновляет эту страницу, карточку, issue и метку ready следующей доступной задачи. Обновление статуса не автоматизировано: задача не становится выполненной от одного коммита или build.

Рабочий каталог должен соответствовать актуальной main. Старый открытый checkout Cursor и прежний чат могут содержать другую ветку и несохранённые правки; GitHub default branch их автоматически не переключает.
