# Состояние тестового стенда, 10 ноября 2026

Снимок прогресса Cursor взят отдельно от его рабочей ветки. Это тестирование разработки на учебных данных.

| Область | Состояние |
|---|---|
| Вход, сессия и серверные роли | API v1; уникальные учётки стенда |
| Блок «Рабочий день» | API v1: учебная подготовка допуска/назначений/задания, смена, работа, окончание, фиксированный учебный объём 1,250, утверждение часов, Excel |
| Общий кабинет / списки старых экранов | Legacy `/api/desk`; managed-смена не обязана появляться в старых счётчиках |
| Качество, материалы, ИД и часть действий остальных экранов | Локальная книга браузера, не общий серверный бизнес-процесс |
| Офлайн-очередь событий/фото | Проверенный headless пакет существует; UI этого снимка ещё не подключён |
| Физические Android/iPhone | Требуют отдельной проверки |

«Подготовить день» — учебный сценарий с заранее заданными идентификаторами/параметрами, не универсальная форма создания заданий. Время старта в учебном блоке сдвигается на две минуты назад для демонстрации ненулевых часов. Этот блок не используется для фактического табелирования сотрудников. Повтор в другой день, другой вкладке или после изменений может требовать доработки Cursor.

Пользовательский тест: руководитель готовит день → работник выполняет четыре действия по порядку → руководитель утверждает часы и скачивает Excel. Подробный фактический результат серверных проверок записывается в отчёте размещения.

Стенд принимает только вымышленные данные. Это промежуточная версия, не завершённый пилот по ТЗ.
