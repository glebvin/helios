# Совместимый аварийный режим для пакета139–144

Основа — принятый17c4918 и схема001–033. Запасной runtime сохраняет текущие чтения, историю, права, проверки приказов и старые квитанции. База и файлы не восстанавливаются из старого dump ради обычного возврата приложения.

В образе возврата установлен `HELIOS_RELEASE_RECOVERY=1`. Он приостанавливает новые количественные корректировки, частичные решения ПТО, записи настройки ПТО и импорты цен:503 `release_write_paused` внутри транзакции, без сохранённой резервации запроса. Точный повтор уже выполненной команды продолжает проверять текущие права и возвращает прежнюю квитанцию. Прежние действия, в том числе полная приёмка/возврат и работа с остатком, остаются.

Это совместимый режим с приостановкой новых действий, не возврат к старому API4319832. Текущая UI и чтения нужны для данных корректировок и разделённых частей. Баннер сообщает ограничение; неподтверждённые команды клиента сохраняют идентичность до возврата основного runtime. Секреты, данные, аккаунты и хранилище образ не содержит.

Перед выпуском: проверить новый и запасной образы на восстановленной копии реального резерва, записать корректировку/частичное решение в основной образ, переключить копию на запасной, проверить историю/суммы/точный повтор/503 без новой квитанции. Отдельно проверить старые001–030 и повтор миграций. До успешных результатов этот файл не является доказательством готовности возврата.
