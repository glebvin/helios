# Кандидат выпуска: смена R13–R17 и принятый интерфейс

Поручение владельца: внимательно проверить и выпустить PR68–72. R18 остаётся отдельной незавершённой работой, R19 не начинать.

## Сохранение и основание

Перед review проверены11 подготовленных файлов в den-rabotnika: индекс, рабочие файлы и приватная копия совпали побайтно. Они сохранены отдельным коммитом `d7e950d39c2865abd0bffff1d04508fc6857ce05`, прямым потомком исходного R17 `5d10f3fa5a94c08d8acf62b7072c1592ba498574`, и fast-forward отправлены в PR72 без force-push. R18 из соседней грязной папки не включён; её изменения отдельно скопированы, ветка и рабочие файлы не переключались.

Пять PR образуют одну последовательную цепочку. Общий кандидат включает актуальную main11de2c1, все исходные коммиты PR68–72, принятые экраны и исправления review. Конфликты разрешены с сохранением прежних исправлений загрузки/повторов/ролей/часового пояса. Принятые app.css, Dialog и NoteMark сохранены; новые числа сервера не анимируются. Включение финальной ветки merge-коммитом сохраняет ancestry всех пяти PR и позволяет GitHub отметить предков объединёнными. Их старые check runs не выдаются за проверку нового кандидата: у R13/R14 исторический UI smoke падал на ожидании заголовка людей, R15 не имел checks текущей вершины. Перед merge требуется полный успешный CI итогового дерева.

## Что исправлено при проверке

- Браузером подтверждено: ошибка фонового чтения дня оставляла кнопку начала смены активной. Теперь неподтверждённое чтение блокирует действия, ошибка видна, повтор восстанавливает экран.
- При недоступном sessionStorage потерянный ответ смены приводил к новому requestId. Добавлено сохранение команды в открытой форме для смены, интервала, объёма и файла. Для перерыва/завершения сравниваются только реально отправляемые поля; повтор сохраняет исходную полную команду. Ключ смены включает объект и день.
- Свайп подтверждает завершение только после отпускания за порогом; короткий быстрый жест больше не срабатывает по скорости, незавершённый жест возвращается. Повтор не создаёт вторую смену/отправку.
- После завершения смены обновляется доступность объёма без reload; внешнее изменение версии перечитывает текущий интервал. Объём не считается принятой работой.
- История смен, интервалы, отчёты и файлы читаются со всех страниц через общий клиент. Закрытая смена короче минуты подписана закрытой.
- CI выявил зависание перехода в «Люди» при завершении начального чтения объекта. Это воспроизведено локально: две анимации управляли одним уходящим элементом. Анимация обновления теперь не применяется к уходящей странице и останавливается при смене раздела; исходный переход и проверки CI сохранены. Контролируемое пересечение включено в браузерный smoke.
- Старые задания остаются читаемыми; команды исполнения и готовности управляемого процесса для них не предлагаются. Серверные права и контракты не менялись.
