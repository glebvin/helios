# Главная и чтение ПТО — R21–R22, 13 ноября 2026

Исходные [PR77](https://github.com/glebvin/helios/pull/77) (`dcb1b3d535a04be3004cd1cc9f8509ac2d3567af`) и [PR78](https://github.com/glebvin/helios/pull/78) (`889f9da617ab35a40501683f08497ade985d1a5a`) проверены отдельным пакетом поверх принятой main `3bf0710b870d57f676b8d4d0509c8ba1b065a90a`.

Это отчёт технической проверки кандидата. Точный опубликованный commit, CI и публичный smoke подтверждаются в [GitHub Releases](https://github.com/glebvin/helios/releases) и `/release.json`; сама main сервер не переключает.

## Поведение и границы

Главная и «Мои дела» director/master читают реальные сводку, задания и дни табеля выбранного объекта. Присутствие, работа и объём — источники сервера, а не приёмка качества. Недоступные качество/ИД/принятый объём подписаны как неподключённые. Учебный DayFlow удалён из обычного кабинета.

ПТО читает факты объёма, файлы и табель; локальной формы «Наша проверка» и кнопки «Принять» в его живом кабинете нет. Файлы скачиваются авторизованно, готовность файла не означает подпись акта. Остальные процессы качества/актов и полная матрица ролей остаются отдельными шагами roadmap.

## Совмещение и исправления ревью

- Конфликт подключения табеля решён сочетанием даты из шапки R21 с ключом входа/объекта из принятого R18–R20. Исправления повторов, полного чтения истории, статусов и экспорта сохранены.
- В исходном кандидате на непустой главной воспроизведено: после сетевого сбоя обновления оставались старые данные, ошибка и кнопка повтора скрывались. Общий reader сводок/ПТО теперь связывает результат с входом, объектом, датой и попыткой; ошибка не выдаётся за прежний успех.
- Списки дел получают все страницы черновиков/согласования; дни табеля для счётчика читаются полностью. Чтение фактов и файлов ПТО не заканчивается на первых25/100 строках. Названия заданий для фактов берутся из разрешённого каталога объекта, а не только из планового дня сообщения.
- Ссылка из дела открывает конкретное задание. После ухода обычная навигация не возвращает старую карточку или однажды открытую вкладку табеля. Ручной выбор периода табеля не затирается обновлением шапки.
- Поздние ответы чтения и скачивания прежнего объекта не подменяют текущий экран и не запускают файл после ухода.
- Таблицы ПТО на390px прокручиваются внутри блока, без разрыва статусов по буквам. В блоке внимания две колонки вместо прежней сетки с отдельным местом для иконки: имя не накладывается на кнопку. Отступы карточек сохранены и у анимированного контейнера. Сохранены существующие палитра, компоненты и композиция.

## Независимая проверка

Собственная PostgreSQL54359, API4359 и preview5217; отдельная синтетическая компания и настоящие director/master/worker/PTO. Непустое задание подготовлено реальными допуском, назначением, фронтом и публикацией. Через API записаны закрытая смена с120000ms присутствия/60000ms работы, объём1.125м³ и реальное PNG-вложение. Для пагинации добавлены отдельные валидные закрытые смены с одним отчётом на смену: всего101 сообщение;101 файловая запись включает один готовый файл и100 ожидающих загрузки. Ограничения сервера не отключались. Общая база, сервер и окружения Cursor не использовались для тестовых записей.

Пройдены70 frontend unit tests, TypeScript, сборка и ссылки51 карточки. В `qa/overview-browser.mjs` —18 браузерных сценариев: непустые источники и совпадение с карточкой/доской, настоящий master, ошибка/повтор, конкретное задание, переходы табеля, настоящий PTO и отсутствие записывающих форм, байты/SHA скачанного PNG,404 чужого файла/403 утверждения,101 отчёт и101 файл, позднее скачивание/чтение, повторный вход, сохранность кабинета worker и390px. Ошибок JavaScript в этих сценариях нет. Визуальные снимки делаются после завершения перехода на нужный экран.

Исходные PR имели зелёные CI, но автор не проверял непустые данные и сетевые ошибки. Это не заменяет перечисленную независимую проверку. Все CI текущего итогового кандидата и main проверяются отдельно перед завершением выпуска.

## Выпуск

API/SQL/worker/domain и серверные права не меняются. Планируется только frontend/gateway с сохранением БД, аккаунтов, API/worker/DB container IDs и проверкой19 бизнес-таблиц. Перед переключением проверяется восстановлением резерв БД и архив файлов. Предыдущая версия для отката — `3bf0710b870d57f676b8d4d0509c8ba1b065a90a`.

R23–R25 выполняются Cursor независимо от этого пакета, от принятой main с R18–R20. Их ветки и папки не входят в выпуск и не меняются. Перед R26 нужна общая принятая версия R21–R25. Физические телефоны, полный offline/PWA и весь пилот этим выпуском не приняты; прежнее предупреждение размера JS и ограничение выбора нескольких закрытых смен для объёма остаются.
