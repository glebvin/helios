## Исправления

И локальный, и staging-вход принимают JSON до2МБ, достаточный для разрешённого файла и Base64. Серверная распаковка ограничена `maxOutputLength` до выделения полного буфера. Импорт берёт свежую роль и держит блокировку членства до завершения команды; повтор проверяет права. Пакет атомарный, старые карточки не переписываются, ФИО не ключ, табельный номер не номер документа. Аккаунты/роли/допуски/назначения не создаются.

UI отбрасывает поздний ответ другого работодателя и предыдущего входа. После неизвестного результата хранится исходная команда с файлом/работодателем/verdictHash/requestId: повтор после reload посылает её же. При недоступном sessionStorage текущая вкладка сохраняет команду в памяти; это не гарантия восстановления после reload без хранилища. Подтверждённая запись показывается отдельно от ошибки чтения; во время неизвестного результата нельзя незаметно заменить пакет. Это не offline-очередь импорта.
