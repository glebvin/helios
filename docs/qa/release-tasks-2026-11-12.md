## Найдено и исправлено

- Форма черновика скрывала ошибку начальной загрузки: браузером воспроизведены0 сообщений/0 кнопок повтора. Теперь ошибка видна, сохранение недоступно до успешного чтения, повтор работает. Ошибка чтения ответственных больше не маскируется пустым списком.
- Зоны, виды, назначенные сотрудники и ответственные читаются со всех страниц. Проверен выбор активной зоны после100-й записи. Архивное исключено для нового задания.
- При смене объекта/дня очищается состояние старых карточек и редакторов. Возврат к доске и фокус перечитывают её. Обычная правка прорабом сохраняет существующего ответственного, даже если список других ответственных этой роли недоступен.
- Работник не запрашивает закрытые справочники и готовность фронта. Прежний просмотр дополнительных ролей сохранён; управляемые команды/фронт не предлагаются legacy-заданиям. Права API не расширялись.
- Конфликт перехода/проверки фронта позволяет явно перечитать задание без ложного уведомления о записи.
- Для потерянного подтверждения проверки фронта сохраняется полная команда, включая исходную версию задания. После reload повтор возвращает прежнюю попытку, вместо записи второй. Серверные версии и идемпотентность не обходятся.
- Краткий сбой фонового чтения объекта/дня больше не закрывает несохранённый черновик задания. Воспроизведена потеря формы; после исправления проверены ошибка связи и восстановление без потери введённого текста. Ошибка остаётся видимой, неподтверждённая доска не используется.
- Интервал задания показывается по часовому поясу компании из API, а не по часовому поясу браузера.
