## Чего в контракте нет

Новые ручки здесь не предлагаются.

- Полного справочника организаций в v1 нет. Имена организаций по-прежнему приходят из `GET /api/desk`.
- `GET /api/v1/projects` возвращает id и name. Адрес и координаты остаются в legacy desk и `POST /api/projects/:id/place`.
- `project_memberships` отдаёт `userId` и роль, без имени. Имя показывается из карточки сотрудника. Пользователь без карточки открывается по его идентификатору.
- Причина возврата и отмены задания в ответе `GET` задания не приходит. Экран помнит её у того, кто её отправил. Отдельной ручки аудита в контракте нет.
- `GET /api/v1/projects/:p/time/days` отдаёт только записанные дни, страницами. Отсутствующей строки нет, и она не считается подтверждённым отсутствием.
- `Overview` прямо помечает качество, простои и готовность ИД как недоступные. Эти нули не считаются фактом.
- Паспорт, скан квалификации и аватар сервер не хранит. `documentReference` — текст реквизитов.
- Задание не отдаёт название зоны и имя ответственного. Рабочий не читает каталог зон и список членств.
- Карточка смены не возвращает координаты и точность. Подтверждённого нулевого объёма с причиной нет. Уже отправленный отчёт этим экраном не редактируется.
