## Чего в контракте нет

Новые ручки здесь не предлагаются.

- Полного справочника организаций в v1 нет. Имена организаций по-прежнему приходят из `GET /api/desk`.
- `GET /api/v1/projects` возвращает id и name. Адрес и координаты остаются в legacy desk и `POST /api/projects/:id/place`.
- `project_memberships` отдаёт `userId` и роль, без имени. Имя можно показать, только если у этого пользователя есть карточка сотрудника.
- Нет одного списка неутверждённых дней по объекту. Обход каждого сотрудника по дню для дашборда не используется.
- `Overview` прямо помечает качество, простои и готовность ИД как недоступные. Эти нули не считаются фактом.
- Паспорт, скан квалификации и аватар сервер не хранит. `documentReference` — текст реквизитов.
