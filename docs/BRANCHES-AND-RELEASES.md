# Ветки и опубликованные версии

## Активная работа

- **main** — основная проверенная база, открывается первой на GitHub.
- **codex/<задача>** — временная ветка одного изменения, например `codex/kartochka-sotrudnika`.
- **Теги archive/** — сохранённая история. Это метки коммитов, не активные ветки; не продолжать из них разработку.

Ветка содержит весь проект, а не только frontend/backend из её названия. 12 ноября исторические archive-ветки заменены одноимёнными аннотированными тегами с проверкой точного commit. Код сохраняется, список активных веток сокращается.

## Настройки работы

Предпочтён squash merge; временные объединённые ветки удаляются. CI запускается на PR с любой базой, push main и вручную; автоматического deploy нет. Доступность технической защиты main зависит от тарифа GitHub для этого приватного репозитория. Фактический результат настройки фиксируется в [отчёте организации](qa/repository-setup-2026-11-11.md); наличие инструкции не считается включённой защитой.

Для связанной цепочки R08–R12/тест-кейсов 12 ноября сохранены merge-коммиты: ancestry исходных PR исключает повторные конфликты при squash родителей. Перед каждым merge проверены CI точного head и равенство итогового дерева. Это ограниченное исключение; обычная настройка отдельных задач — squash. [Отчёт пакета](qa/release-tasks-2026-11-12.md).
