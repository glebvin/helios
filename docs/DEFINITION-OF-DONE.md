# Когда шаг действительно готов

Отметьте только выполненные пункты. Неприменимое условие поясните; физический телефон не заменяется эмулятором.

- [ ] Реализовано именно поведение карточки, зависимости приняты.
- [ ] Контракт и права сверены с текущим сервером; связанные чтения согласованы с записью.
- [ ] Нет фиктивного серверного успеха, подмены данных локальной книгой или расширения ролей.
- [ ] Повтор запроса, устаревшая версия, отсутствие доступа/данных и сетевая ошибка обработаны соразмерно сценарию.
- [ ] Результат подтверждён после обновления; при общей записи проверен другой уполномоченный вход.
- [ ] Выполнены подходящие автоматические проверки и сборка; в PR приведены команды/результаты, а не «всё работает».
- [ ] Агент прошёл живой браузерный сценарий; использованы отдельные QA-данные.
- [ ] Есть снимки до/после на одинаковых данных и мобильной ширине; сохранены принятый стиль и соседний сценарий.
- [ ] Владелец увидел работающий preview; продуктовые замечания учтены.
- [ ] Документы и статус задачи соответствуют фактам; ограничения перечислены.
- [ ] PR готов к объединению; секретов и лишних файлов нет.
- [ ] Понятен откат кода; для затронутых данных/SQL — отдельная совместимая процедура.

## Выкладка — дополнительная приёмка

Проверенный commit, совместимые миграции, резерв при изменениях данных, известная предыдущая версия, публичная проверка login/сценария/health. Не запускать seed/reset на активной базе. Если схема менялась, возврат только старого образа может быть недостаточен.
