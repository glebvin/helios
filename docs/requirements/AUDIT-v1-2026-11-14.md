## Автоматическая проверка

`python3 scripts/check-docs.py`: ссылки входных документов, всех51 карточки и requirements; уникальность IDs, соответствие GitHub mapping, отсутствие циклов исходных зависимостей; синхронность v1.0 sources/notes между карточками и JSON; сохранение исторического покрытия4.0; ровно24 строкиT и6решенийD. `git diff --check` проверяет whitespace. Эти проверки выполняются в project-checks; они не проверяют все бизнес-требования за человека.

Полный CI текущего commit отслеживается в PR/Checks. Этот отчёт не подменяет неизвестный статусCI обещанием успеха. Сверка GitHub descriptions записывается отдельным датированным блоком с сохранением исходного текста; текущие статусы реализации не меняются от исправления формулировки.
