# Кабинет: вход, объект, список и карточка

Шаги R01–R03. Проверяет, что человек попадает в свой кабинет, видит выбранный объект и день, а карточка сотрудника сохраняется на сервере.

## K1. Вход по роли

1. Войдите руководителем. Откройте «Люди», «Задания», «Объект», «Настройки».
2. Выйдите. Войдите прорабом. «Объект» есть, кнопок записи справочника нет.
3. Выйдите. Войдите работником. Кабинет уже, раздела «Задания» с доской руководителя нет. Есть своё «Задание».

Ожидание: у каждой роли свой набор разделов. Чужие кнопки записи не появляются.

## K2. Объект и день в шапке

1. Руководителем выберите «Учебная площадка». Запомните день в шапке.
2. Переключите объект на вторую площадку, затем вернитесь.
3. Обновите страницу.

Ожидание: день и объект остаются теми, что подтвердил сервер. Данные второй площадки не подменяют первую. Пока объект или день не подтверждены, списки не делают вид, что запись уже выбрана.

## K3. Список сотрудников

1. «Люди». Найдите известные карточки: работник, прораб и карточку без входа.
2. Пролистайте список, если есть страницы.

Ожидание: имена приходят с сервера. Пустой поиск по несуществующему имени не показывает чужие карточки. Ошибка чтения не выглядит как пустая компания.

## K4. Карточка сотрудника

1. Откройте карточку. Измените заметное поле, например телефон, и сохраните.
2. Дождитесь всплывающего подтверждения. Обновите страницу и откройте того же человека.
3. Создайте сотрудника с вымышленным именем и сохраните.

Ожидание: правка и новая карточка остаются после обновления. Новая карточка сама не создаёт логин. Пока сервер не ответил, успех не показывается. Если версия карточки уже изменилась в другом окне, повтор без чтения актуальной записи не затирает её молча.
