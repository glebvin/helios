# Сообщение о проблеме безопасности

Не публикуйте секреты, пароли, токены, персональные данные или содержимое рабочих вложений в issue/PR.

Сообщите владельцу репозитория по уже согласованному приватному каналу. Укажите версию, безопасные шаги воспроизведения, затронутые права/данные и ожидаемое поведение. Новый адрес поддержки здесь не выдумывается.

Если секрет попал в Git, удалить строку недостаточно: сначала отозвать/заменить секрет, затем согласовать очистку истории. Историю самостоятельно не переписывать.

Это проект в разработке. Тестовые общие пароли и демонстрационные данные не являются моделью доступа для реальных клиентов. Возможности серверной изоляции должны проверяться отрицательными сценариями; скрытая кнопка не заменяет проверку API.
